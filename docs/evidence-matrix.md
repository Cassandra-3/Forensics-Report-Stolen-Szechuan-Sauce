## Confidence definitions

- **High:** directly supported by a specific artifact with a clear interpretation.
- **Medium:** supported, but meaningful context or an independent source is missing.
- **Low:** plausible hypothesis with insufficient evidence for a firm conclusion.

## Production evidence-handling expectations

A production-quality investigation would record:

- source and acquisition date;
- archive and extracted-artifact hashes;
- custody transfers;
- original and working-copy locations;
- tool versions and analysis dates;
- time-zone handling;
- every transformation or export; and
- references from each conclusion to the supporting artifact.

The classroom report includes screenshots for many findings. This repository summarizes them without redistributing the original forensic datasets.
